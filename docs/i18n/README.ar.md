**بيئة تشغيل موثوقة للوكلاء عبر جميع قنوات المحادثة.**

MicroClaw هو نظام تشغيل للوكلاء قابل للاستضافة الذاتية ومكتوب بلغة Rust. تشترك Telegram وDiscord وSlack وFeishu/Lark والويب والمحولات الأخرى في حلقة وكيل واحدة مستقلة عن القناة، وطبقة LLM مستقلة عن المزوّد، والأدوات والذاكرة والسياسات وآلية الاستعادة نفسها.

صُمم للأعمال التي تستمر لأكثر من طلب واحد: استخدام الأدوات متعدد الخطوات، والجلسات القابلة للاستئناف، والتسليم المتين، والذاكرة الدائمة، والمهام المجدولة، والمهارات، وMCP، والوكلاء الفرعيون تعمل جميعها داخل البيئة نفسها.

## البدء السريع

التثبيت على macOS أو Linux:

```sh
curl -fsSL https://microclaw.org/install.sh | bash
```

على Windows PowerShell:

```powershell
iwr https://microclaw.org/install.ps1 -UseBasicParsing | iex
```

الإعداد والتشغيل:

```sh
microclaw doctor
microclaw setup
microclaw start
```

ثم افتح [http://127.0.0.1:10961](http://127.0.0.1:10961). راجع [دليل البدء](../getting-started.md) لاستخدام Homebrew وDocker والبناء من المصدر وتوافق Linux والتثبيت كخدمة.

## لماذا MicroClaw

- **بيئة واحدة وواجهات متعددة:** السلوك وسياسات الأمان نفسها عبر جميع القنوات.
- **عمل قابل للاستعادة:** تستأنف الجلسات ونقاط التحقق الآمنة والمهام المجدولة والتسليم بعد إعادة التشغيل.
- **حرية اختيار المزوّد:** يعمل Anthropic والخدمات المتوافقة مع OpenAI والنماذج المحلية عبر نموذج داخلي موحد.
- **نقاط توسعة واضحة:** المهارات وخوادم MCP والإضافات وHooks والأدوات ومحولات القنوات.
- **استضافة ذاتية بسيطة:** خدمة Rust مع SQLite مدمج، من دون اشتراط قاعدة بيانات متجهية منفصلة.
- **أمان موحّد:** موافقات الأدوات والصلاحيات محدودة النطاق وسياسة الاتصال الخارجي والعزل والتنقيح وسجلات التدقيق.

## القدرات الرئيسية

- أدوات متعددة الخطوات، وتخطيط، وتحديثات للتقدم، ووكلاء فرعيون
- ذاكرة دائمة في الملفات وSQLite، واسترجاع دلالي، وتعلّم خاضع للحوكمة
- مهام مجدولة، وضغط للسياق، وجلسات قابلة للاستئناف
- Telegram وDiscord وSlack وFeishu/Lark والويب وقنوات أخرى كثيرة
- واجهة ويب محلية وواجهات HTTP وSSE وWebSocket وA2A وACP وMCP
- عزل Docker وسياسات وصول وتشخيص ومقاييس وتتبع

راجع [فهرس الأدوات المولّد](../generated/tools.md) و[مصفوفة المزوّدين](../generated/provider-matrix.md) للاطلاع على القوائم الحالية.
