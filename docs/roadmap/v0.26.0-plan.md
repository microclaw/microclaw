# MicroClaw v0.26.0 execution plan

Status: **Delivered**
Updated: **2026-11-06**

MicroClaw 0.26.0 makes MicroClaw Code a fully separate product from the
MicroClaw Server. Both come from the same Agent Engine, but each installs,
updates, configures and uninstalls on its own, and neither reads the other's
configuration, data or environment. No compatibility with the old shared
layout is kept.

## Scope

- Code home `~/.mccode` (`MCCODE_HOME`) instead of `~/.microclaw/code`;
  nothing is migrated (#551).
- No model credentials from `MICROCLAW_CONFIG` or
  `~/.microclaw/microclaw.config.yaml`; only `--config`, `MCCODE_CONFIG`,
  `~/.mccode/config.yaml` or a settings profile (#551).
- `MCCODE_*` variables only; the engine's Server variables
  (`MICROCLAW_CONFIG`, `MICROCLAW_SKILLS_DIR`, `MICROCLAW_LOCAL_SANDBOX`,
  `MICROCLAW_PATH_ALLOWLIST`, …) are replaced or cleared before `mccode`
  starts its runtime (#551).
- Managed settings under `/etc/mccode`; the OS sandbox hides `~/.mccode`
  (#551).
- Role model examples stay on one profile; `model.roles.subagent` is
  documented as unused (#550).

Not changed: the per-repository `.microclaw/` project directory and the
Server's `microclaw code` forwarder.

## Acceptance gates

- Every Rust and UI package reports `0.26.0`
  (`scripts/ci/check_version_alignment.sh`).
- `cargo clippy --workspace --all-targets -D warnings` and
  `cargo test --workspace` (1894 tests) pass locally; Main CI and Extended CI
  succeed for the tagged commit.
- The `v0.26.0` Release Assets workflow publishes `microclaw`,
  `microclaw-full` and `mccode` archives, `SHA256SUMS.txt` and containers.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.26.0`; the Homebrew tap serves 0.26.0.
