# MicroClaw v0.29.0 execution plan

Status: **Delivered**
Updated: **2026-11-10**

MicroClaw 0.29.0 makes `/goal` work everywhere MicroClaw Code runs and
brings the common terminal commands to Zed.

## Scope

- `/goal` in Zed (`mccode acp`) and `mccode -p`, sharing one loop with the
  terminal UI (`microclaw-code-core::goal`). `--until <command>` is the
  judge; `--rounds N` sets the limit (default 8). `-p` exits 1 when the goal
  is not reached and `--json` adds a `goal` object (#565).
- Stricter goal judging: `GOAL COMPLETE` counts only as the last line,
  `GOAL BLOCKED: <reason>` stops the goal, two idle rounds stop it as
  stalled.
- Zed gains `/btw`, `/check`, `/diff`, `/rewind [N]`, `/status`, `/export`
  and `/init`.
- Released as a minor version because it adds features; the published
  crates (`microclaw-core`, `-engine`, `-sdk`) have no source changes since
  0.28.0 (#567).

## Acceptance gates

- Every Rust and UI package reports `0.29.0`
  (`scripts/ci/check_version_alignment.sh`).
- `cargo deny check advisories` and Security Audit pass.
- Main CI and Extended CI succeed for the tagged commit.
- The `v0.29.0` Release Assets workflow publishes `microclaw` and `mccode`
  archives for five targets and `SHA256SUMS.txt`.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.29.0`; the Homebrew tap serves 0.29.0.
