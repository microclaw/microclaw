# MicroClaw v0.29.1 execution plan

Status: **Delivered**
Updated: **2026-11-11**

MicroClaw 0.29.1 fixes the `openai-codex` provider, which stopped working
once its OAuth token expired.

## Scope

- The token from `~/.codex/auth.json` was read and refreshed only when the
  provider was created at startup, so a long-running Server or `mccode`
  session sent an expired token and every request failed with HTTP 401
  until a restart. The auth file is now read before every request, the
  token is refreshed (and written back) five minutes before it expires, and
  a 401 triggers one refresh and retry. Concurrent refreshes are serialised.
  The startup refresh's blocking HTTP client inside the async runtime is
  gone (#569).
- Released as a patch: `cargo semver-checks --release-type patch` passes for
  `microclaw-core`, `microclaw-engine` and `microclaw-sdk` (#570).

## Acceptance gates

- Every Rust and UI package reports `0.29.1`
  (`scripts/ci/check_version_alignment.sh`).
- `cargo deny check advisories` and Security Audit pass.
- Main CI and Extended CI succeed for the tagged commit.
- The `v0.29.1` Release Assets workflow publishes `microclaw` and `mccode`

- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
