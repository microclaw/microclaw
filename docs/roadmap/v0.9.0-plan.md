# MicroClaw v0.9.0 execution plan

Status: **Active**
Updated: **2026-10-07**

MicroClaw 0.9.0 moves the optional Matrix channel to matrix-sdk 0.19 and the
workspace to rusqlite 0.40. The minor version reflects the rusqlite bump, which
`microclaw-core` exposes through its optional `sqlite-errors` feature; there is
no other SDK API change.

## Scope

- matrix-sdk 0.16 → 0.19 for `channel-matrix` (fixes RUSTSEC-2026-0318 and
  RUSTSEC-2026-0292, drops the unmaintained `bitmaps`), with the
  `rustls-aws-lc-rs` TLS backend (#510).
- rusqlite 0.37 → 0.40 workspace-wide, `fallible_uint` keeping the existing
  integer conversions.
- Pinned toolchain 1.95.0 → 1.96.1; workspace MSRV stays 1.93 for builds
  without Matrix.
- `@assistant-ui/react-markdown` 0.14.7; unified Discord community links.

## Acceptance gates

- Every Rust and UI package reports `0.9.0`.
- Main CI and Extended CI succeed for the release commit.
- `microclaw-core`, `microclaw-engine`, and `microclaw-sdk` publish at `0.9.0`
  and pass the public API compatibility check.
- The `v0.9.0` workflow publishes verified binaries (including the first
  Windows `full` build with aws-lc) and multi-architecture containers, and the
  complete Release Assets workflow is green.
