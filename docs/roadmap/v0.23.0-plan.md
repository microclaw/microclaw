# MicroClaw v0.23.0 execution plan

Status: **Delivered**
Updated: **2026-11-05**

MicroClaw 0.23.0 delivers the 0.21–0.23 milestones of
[`mccode-next-plan-cn.md`](./mccode-next-plan-cn.md) in one release (#538,
#539, #540, plus the Keenable search backend #526 and the release/SDK CI
fixes #535, #536).

## Scope

- Token-aware context engine: per-model windows, tool-output pruning,
  structured incremental summaries that re-inject the user's words and the
  files changed, fallback digest, `/context`, `ContextCompacted` events,
  long-session eval cases.
- Model-managed context: budget hints, opt-in `context_note` /
  `rewind_context`, the read-only `explore` helper with project agents,
  `handoff_session` / `/handoff`.
- MicroClaw Code: project memory, language-server diagnostics, hooks, custom
  slash commands, `@image` input (also over ACP), `--worktree` tasks,
  `review --pr`, `/export`, `--max-session-tokens`, Windows sandbox notices.
- Opt-in Anthropic context editing; Keenable web-search backend.

## Acceptance gates

- Every Rust and UI package reports `0.23.0` (`check_version_alignment.sh`).
- Main CI and Extended CI succeed for the release commit.
- The `v0.23.0` Release Assets workflow publishes `microclaw`,
  `microclaw-full` and `mccode` archives (Linux binaries need glibc ≤ 2.39),
  `SHA256SUMS.txt` and containers.
- `install-mccode.sh` installs and runs `mccode 0.23.0`.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.23.0` and pass the registry consumer check.
