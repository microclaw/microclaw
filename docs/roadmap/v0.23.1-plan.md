# MicroClaw v0.23.1 execution plan

Status: **In progress**
Updated: **2026-11-05**

MicroClaw 0.23.1 is the first real-model test pass over the 0.21–0.23
MicroClaw Code features (phase 1 of
[`next-plan-2026-11-cn.md`](./next-plan-2026-11-cn.md)). Everything below was
run with DeepSeek (`deepseek-flash`, i.e. DeepSeek-V4.1-Flash, and
`deepseek-v4-pro`) on macOS arm64, in isolated `MICROCLAW_CODE_HOME`
directories. The fixes are listed in the CHANGELOG.

## What was tested

| Area | How | Result |

### Eval results

`mccode eval apps/microclaw-code/eval/cases` (JSON Lines, `seconds` /
`requests` / `input_tokens` / `compactions`):

| Case | 0.20.0 · flash | 0.23.0 · flash | 0.23.1 · flash | 0.23.1 · v4-pro |
|---|---|---|---|---|
| add-flag | PASS · 12 s · 5 req · 65k | PASS · 10 s · 6 req · 80k | PASS · 10 s · 5 req · 66k | PASS · 10 s · 4 req · 53k |
| fix-greeting | PASS · 6 s · 4 req · 52k | PASS · 8 s · 4 req · 53k | PASS · 7 s · 4 req · 53k | PASS · 9 s · 4 req · 53k |
| long-session-recall | FAIL (no `followups` in 0.20) | PASS · **0 compactions** | PASS · 3 compactions | PASS · 1 compaction |
| long-session-steps | FAIL (no `followups` in 0.20) | PASS · 1 compaction | PASS · 3 compactions | PASS · 1 compaction |

The long-session cases could not be compared with 0.20.0, which ignores
`followups`. In 0.23.0, `long-session-recall` never compacted: its 12k window
was below the fixed prompt (system prompt + tool definitions, about 13k
tokens), and the 24k verbatim tail meant there was never anything to
summarize. 0.23.1 caps the tail, raises the case windows above the fixed
prompt, and adds `min_compactions: 1` so these cases fail when they do not
compact. The 0.21 goal "25% fewer tokens per task" is still not measured:
the cases are too small for it, which is a follow-up for the eval set.

## Not covered

- Windows and Linux (macOS arm64 only); Zed itself (ACP was driven by a
  script that speaks the same protocol); typescript-language-server and
  gopls; `--remote`; `review --pr --post`.

## Acceptance gates

- Every Rust and UI package reports `0.23.1`.
- `cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`
  and `cargo test --workspace` pass locally; Main CI and Extended CI succeed
  for the release commit.
- `cargo semver-checks` accepts a patch bump for the public crates.
- The `v0.23.1` Release Assets workflow publishes `microclaw`,
  `microclaw-full` and `mccode` archives (Intel macOS cross-compiled on Apple
  Silicon for the first time), `SHA256SUMS.txt` and containers.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.23.1`; the Homebrew tap serves 0.23.1.
