# MicroClaw v0.25.0 execution plan

Status: **Delivered**
Updated: **2026-11-06**

MicroClaw 0.25.0 is the MicroClaw Code interaction and configuration release.
It ships the planned 0.24 (TUI), 0.25 (settings and permissions) and 0.26
(innovations) together; the item-by-item status is in section 10 of
[`mccode-ux-config-plan-2026-11-cn.md`](./mccode-ux-config-plan-2026-11-cn.md),
and the real-model (DeepSeek) test pass is in section 10.1 of the same file.

## Scope

- TUI: theme tokens and 11 built-in themes, Markdown and syntax highlighting,
  diffs with line numbers and side-by-side layout, grouped tool cards, side
  panel, render cache, inline mode.
- Interaction: queue vs steer, `/` and `@` pop-ups, Ctrl+P palette, prompt
  history, `$EDITOR`, `!` shell, paste chips and clipboard images, transcript
  pager, rewind, `/btw`, notifications.
- Configuration: four settings layers with a JSON Schema, `allow` / `ask` /
  `deny` rules enforced through the engine `ToolGate`, Claude Code-compatible
  hooks, `tui.*` keys, model profiles and per-role models, `mccode config`,
  `/configure`, `mccode import`.
- Innovations: approvals and notifications pushed to Telegram / Discord /
  Slack / Feishu, per-turn receipts, hunk-level review, `/goal` with checks as
  the finish line, network-domain visibility.

## Acceptance gates

- Every Rust and UI package reports `0.25.0`
  (`scripts/ci/check_version_alignment.sh`).
- `cargo clippy --workspace --all-targets -D warnings` and
  `cargo test --workspace` (1893 tests) pass locally; Main CI and Extended CI
  succeed for the tagged commit.
- The `v0.25.0` Release Assets workflow publishes `microclaw`,
  `microclaw-full` and `mccode` archives, `SHA256SUMS.txt` and containers.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.25.0`; the Homebrew tap serves 0.25.0.
