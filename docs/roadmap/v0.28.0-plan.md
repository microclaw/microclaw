# MicroClaw v0.28.0 execution plan

Status: **Delivered**
Updated: **2026-11-09**

MicroClaw 0.28.0 removes the Matrix channel and fixes three security
advisories. The Matrix SDK pinned `rusqlite` 0.40, and with it a vulnerable
bundled SQLite, for every product built from this repository; nothing
showed that anyone used the channel (the `microclaw-full` archives of
v0.27.0 had 11 downloads in all, and no user ever filed a Matrix issue).

## Scope

- RUSTSEC-2026-0462: `rmcp` 3.9 (from 1.8). The MCP Streamable HTTP client
  caps response bodies.
- RUSTSEC-2026-0463: `openssl` 0.10.82.
- RUSTSEC-2026-0459: `rusqlite` 0.41, which bundles SQLite 3.54.1
  (`libsqlite3-sys` 0.39.1).
- Removed: the Matrix channel, the `channel-matrix` and `full` Cargo
  features, and the `microclaw-full` release archives and Homebrew formula
  (`formula_renames.json` moves installs to `microclaw`). The
  `install.sh --full` / `install.ps1 -Full` flags only print a notice. Also
  gone: the snap feature, the web UI channel card, the setup wizard entry
  and the docs. A `channels.matrix` config block is ignored with a warning.
  Six `cargo deny` exceptions that only Matrix's dependencies needed are
  removed.
- Released as a minor version because removing a channel and a release
  variant breaks anyone who used them (#564).

## Acceptance gates

- Every Rust and UI package reports `0.28.0`
  (`scripts/ci/check_version_alignment.sh`); `cargo semver-checks` passes.
- `cargo deny check advisories` and Security Audit pass without the Matrix
  exceptions.
- Main CI and Extended CI succeed for the tagged commit.
- The `v0.28.0` Release Assets workflow publishes `microclaw` and `mccode`
  archives for five targets, `SHA256SUMS.txt` and containers, and no
  `microclaw-full` archives.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.28.0`; the Homebrew tap serves 0.28.0 and retires `microclaw-full`.
