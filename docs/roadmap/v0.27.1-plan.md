# MicroClaw v0.27.1 execution plan

Status: **Delivered**
Updated: **2026-11-09**

MicroClaw 0.27.1 fixes five problems found by testing MicroClaw Code 0.27.0
in Zed and in the terminal with Anthropic's `claude-opus-5`, including image
prompts.

## Scope

- Anthropic usage counts prompt-cache reads and writes as input tokens,
  streamed and not, in every product; an `output_tokens`-only
  `message_delta` no longer drops the input count. Token counts, cost, the
  context meter and mid-turn compaction now see the real prompt size (#562).
- The Zed model selector and the TUI `/model` list offer only presets that
  are real model names (`ModelPreset::model_name`), not family ids such as
  `claude-sonnet` (#562).
- `mccode acp`: a permission request keeps the visible call's title, run
  errors are part of the reply, and tool titles are Markdown code spans
  (#562).

Tested by hand with `claude-opus-5` before the release: in Zed, approved
commands keep their titles and the model list is `claude-opus-5` only; in
the terminal, the same task reports 133.7k input tokens and 10% context
instead of 14 and 0%.

## Acceptance gates

- Every Rust and UI package reports `0.27.1`
  (`scripts/ci/check_version_alignment.sh`); `cargo semver-checks` finds no
  semver update required for a patch.
- Main CI and Extended CI succeed for the tagged commit.
- The `v0.27.1` Release Assets workflow publishes `microclaw`,
  `microclaw-full` and `mccode` archives, `SHA256SUMS.txt` and containers.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.27.1`; the Homebrew tap serves 0.27.1.
