# MicroClaw v0.20.0 execution plan

Status: **Delivered**
Updated: **2026-11-04**

MicroClaw 0.20.0 is the first release of **MicroClaw Code** (`mccode`), the
terminal coding agent, next to MicroClaw Server and the Rust SDK. The version
jumps from 0.11 to 0.20 to mark the size of the change: a new product, new
public SDK session APIs and new engine tools.

## Scope

- MicroClaw Code (#527–#531): full-screen TUI and `-p` mode, `plan` / `ask` /
  `auto` modes, in-run approvals and per-project command allow rules, project
  trust, automatic verification with fix rounds, `/undo` `/rewind` `/review`
  `/model` `/cost` `/compact` `/fork`, local OS sandbox (bubblewrap, Seatbelt,
  Landlock fallback), `mccode acp` for Zed and other ACP editors,
  `mccode mcp-server`, remote runs on a paired Server, `mccode eval`,
  `mccode update`.
- Engine and SDK: `apply_patch`, gitignore-aware `glob` / `grep`, stale-read
  guard, `bash_input` and background processes, approval broker, unified
  approval policy, single agent-loop entry, SDK checkpoint / usage / model
  override / compact / fork APIs.
- Packaging: separate `mccode-<version>-<target>` release archives, the
  `mccode` Homebrew formula, and `install-mccode.sh` / `install-mccode.ps1`.
- Docs and site: a MicroClaw Code section (install, usage, Zed and editors,
  remote Server) and a focus on Server, Code and the SDK (#532).

## Acceptance gates

- Every Rust and UI package reports `0.20.0`
  (`scripts/ci/check_version_alignment.sh`).
- Main CI and Extended CI succeed for the release commit.
- The `v0.20.0` Release Assets workflow publishes verified `microclaw` and
  `mccode` archives for macOS, Linux and Windows, `SHA256SUMS.txt`, and
  multi-architecture containers.
- `install-mccode.sh` installs `mccode 0.20.0` from the release.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.20.0`.
- The Homebrew tap serves `microclaw`, `microclaw-full` and `mccode` at
  `0.20.0`.

- Linux glibc fix: the [first assets run](https://github.com/microclaw/microclaw/actions/runs/41889378487) built x86_64 Linux on a newer `ubuntu-latest` image, so those binaries needed glibc 2.43. #535 pinned the build to Ubuntu 24.04 and added a glibc 2.39 release gate; the [assets re-run](https://github.com/microclaw/microclaw/actions/runs/41909948285) replaced the archives in place. The x86_64 Linux `microclaw` and `mccode` now need glibc 2.39
- Install check: `install-mccode.sh` installed `mccode 0.20.0` on x86_64 Linux from the published release with a verified checksum; the downloaded `microclaw-0.20.0-x86_64-linux-gnu.tar.gz` matches `SHA256SUMS.txt` and reports `microclaw 0.20.0`
- SDK: `microclaw-core`, `microclaw-engine` and `microclaw-sdk` 0.20.0 published by the [Publish Rust SDK Crates run](https://github.com/microclaw/microclaw/actions/runs/41903886736). Its final registry check ran before the crates.io index served the new version and failed; `check_sdk_registry_release.sh 0.20.0` passed with the minimal, standard and full presets shortly after, and #536 makes the check wait for the index
- Homebrew: not published for 0.20.0. The tap stayed at 0.11.1 until 0.23.0, which added the `mccode` formula ([`379bb4a`](https://github.com/microclaw/homebrew-tap/commit/379bb4a))
