# MicroClaw v0.31.0 execution plan

Status: **Delivered**
Updated: **2026-11-12**

MicroClaw 0.31.0 delivers the 0.31 items (N5–N7) of
[`mccode-competitive-plan-2026-11-cn.md`](./mccode-competitive-plan-2026-11-cn.md)
and ships the desktop app M1 preview
([`mccode-desktop-plan-2026-11-cn.md`](./mccode-desktop-plan-2026-11-cn.md)),
merged before the release at the user's request.

## Scope

- **N5:**
  - A private memory per repository in
    `~/.mccode/projects/<repo>-<hash>/memory.md`, keyed by the main checkout
    so worktrees share it.
  - The shared `.microclaw/memory.md` and the private file are both in the
    prompt of every turn. A stated preference goes to the private file only.
  - Writing the private file skips the outside-the-project approval.
  - `/memory [shared|private|show]`.
  - `mccode import claude|codex` imports Claude Code auto memory and Codex
    memories.
- **N6:**
  - Plugins in the Claude Code layout: commands (`/name`, `/plugin:name`),
    agents, skills, hooks and MCP servers, with `${CLAUDE_PLUGIN_ROOT}`
    resolved.
  - Marketplace sources (`git-subdir`, `github`, `url`) are followed.
  - `mccode plugin add|list|update|enable|disable|remove` and `/plugins`.
  - New hook and MCP commands are confirmed on install and on update.
  - Project plugins load only in trusted projects.
  - Engine `extra_agents_dirs`, `extra_skills_dirs` and `extra_mcp_configs`;
    SDK `plugin_sources`.
- **N7:**
  - The terminal UI compacts a large session that has been idle for 90% of
    the Anthropic prompt-cache TTL.
  - `ContextUsage.prompt_cache_ttl`.
  - `tui.idle_compact: false` turns it off.
- **Desktop M1 (#575):** a GPUI macOS app in `apps/microclaw-code-desktop`,
  built from source; not signed or distributed yet.
- **Fixes found with a real model:**
  - The bounded `glob` literal fallback (a plan-mode search from `$HOME`
    had hung for 3 h).
  - `activate_skill` in plan mode and read-only profiles.
  - `-p` reports unknown `/commands`.
  - No empty plugin directories are left after removal.
  - The system prompt explains the `<context_budget>` line.
- Released as a minor: new public fields on `Config`, `ContextUsage` and
  the Code types (#576).

## Acceptance gates

- Every Rust and UI package, the desktop crate and its `Info.plist` report
  `0.31.0` (`scripts/ci/check_version_alignment.sh`).
- Workspace tests (1974 passed), clippy (`-D warnings`), fmt and
  `cargo deny check advisories` pass; the desktop crate passes
  `clippy --locked` and `test --locked`.
- Real-model run with DeepSeek `deepseek-v4-flash`: 14 `mccode -p`
  scenarios and 7 pty-driven TUI checks covering N1–N7 pass. Details are in
  section 11 of the competitive plan.
- Main CI and Extended CI succeed for the tagged commit.
- The `v0.31.0` Release Assets workflow publishes `microclaw` and `mccode`
  archives for five targets and `SHA256SUMS.txt`.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.31.0`; the Homebrew tap serves 0.31.0.
