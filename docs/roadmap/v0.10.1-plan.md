# MicroClaw v0.10.1 execution plan

Status: **Delivered**
Updated: **2026-10-24**

MicroClaw 0.10.1 is a hotfix for the Web UI. It keeps the 0.10 runtime and
SDK contract unchanged and only repairs the embedded web bundle.

## Problem

Since the 2026-10-05 web dependency bump (`7fe2f8d4`) the lockfile resolved
the transitive `@assistant-ui/tap` to 0.9.20. tap 0.9.13+ carries a
`getSnapshot` loop guard whose matching fix in `@assistant-ui/core` only
shipped in the 0.15 line; the 0.14 line that `@assistant-ui/react-ui` still
requires is frozen on core 0.2.23. The first keystroke in the composer
therefore threw `Maximum update depth exceeded` and froze the page
([#517](https://github.com/microclaw/microclaw/issues/517)). v0.8.0, v0.9.0
and v0.10.0 all shipped that pair.

## Fix

- `web/package.json` pins `@assistant-ui/tap` to 0.9.12 (the last release
  before the guard) through npm `overrides`; the lockfile is re-resolved.
- Dependabot ignores `@assistant-ui/tap >= 0.9.13` next to the existing
  `@assistant-ui/react < 0.15` hold, so the pair cannot drift again.
- Moving the web UI to `@assistant-ui/react` 0.15 (which removes the need
  for the pin) is tracked separately.

## Acceptance gates

- Every Rust and UI package reports `0.10.1`.
- Typing in the Web UI composer with the rebuilt bundle no longer logs
  `Maximum update depth exceeded`, and a message can be sent.
- `cargo semver-checks` accepts a patch bump for the public crates.
- Main CI and Extended CI succeed for the release commit.
- The `v0.10.1` Release Assets workflow publishes verified binaries.
