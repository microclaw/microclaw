# MicroClaw v0.27.0 execution plan

Status: **Delivered**
Updated: **2026-11-07**

MicroClaw 0.27.0 makes MicroClaw Code a first-class agent in Zed through
`mccode acp`, and the website, docs and READMEs now recommend Zed as the main
way to use it, with the terminal interface as the alternative.

## Scope

- `mccode acp` on ACP protocol v1 (schema 1.15): mode and model selectors,
  slash commands, context and cost indicator, real file diffs, absolute
  paths, project checks as tool cards, thread titles and history
  (`session/list`, resume, close) and a sign-in prompt that runs
  `mccode setup` (#554).
- Zed findings: `session/list` without `cwd` lists every project's sessions
  (Import Threads), edit diffs rebuilt from the edit's own diff, attachment
  titles (#555).
- Zed-first website, docs and READMEs, Zed download guidance, doc
  corrections from an audit against the code, and Docusaurus v4 admonition
  syntax (#556, #557).
- The TUI `/config` masks API keys (#557).

Tested by hand in Zed with DeepSeek: mode picker, reconnect through
`session/load`, attachments, permission cards (approve once, always allow),
diffs, check cards, the context ring, the `/` menu and `/cost`.

## Acceptance gates

- Every Rust and UI package reports `0.27.0`
  (`scripts/ci/check_version_alignment.sh`).
- Main CI and Extended CI succeed for the tagged commit.
- The `v0.27.0` Release Assets workflow publishes `microclaw`,
  `microclaw-full` and `mccode` archives, `SHA256SUMS.txt` and containers.
- `microclaw-core`, `microclaw-engine` and `microclaw-sdk` publish at
  `0.27.0`; the Homebrew tap serves 0.27.0.
