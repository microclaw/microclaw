# MicroClaw v0.30.0 execution plan

Status: **Delivered**
Updated: **2026-11-12**

MicroClaw 0.30.0 delivers the 0.30 items (N1–N4) of
[`mccode-competitive-plan-2026-11-cn.md`](./mccode-competitive-plan-2026-11-cn.md):
the everyday gaps found by comparing MicroClaw Code with Claude Code, Codex
CLI and OpenCode.

## Scope

- **N1:**
  - Ctrl+B moves a running shell command to the background. In a workspace,
    foreground `bash` runs through the `ProcessRegistry`.
  - `/jobs` in the terminal and in Zed lists, shows and stops background
    commands and sub-agent runs, also while a turn runs.
  - The side panel moves to Ctrl+].
- **N2:**
  - `/rewind` cuts the conversation back as well as restoring the files.
    Each turn start records a session mark: the message count plus a prefix
    fingerprint. A conversation compacted since then is left alone.
  - You can rewind both, files only or conversation only. When the files
    and the conversation may disagree, the next prompt tells the model.
- **N3:**
  - `model.roles.subagent` (`aux_models.subagent`) runs `sessions_spawn`
    and `explore`.
  - `sessions_spawn` takes `agent` to run a project agent.
  - Project agents gain a `tools:` list that can only narrow the tools.
- **N4:**
  - `permissions.reviewer: off | advise | approve`. With `approve`, the
    reviewer approves the calls it rates SAFE in ask mode; everything else
    still asks.
  - The turn receipt lists what the reviewer approved.
- Released as a minor: new public fields on `Config`, `AuxModels` and the
  Code types (#573).
