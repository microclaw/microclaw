# MicroClaw v0.8.0 execution plan

Status: **Delivered**
Updated: **2026-10-05**

MicroClaw 0.8.0 is a hardening release for multi-user deployments. The minor
version reflects the public `allow_governance_file_writes` field added to
`microclaw-engine` `Config`; there is no other SDK API change.

## Scope

- Governance file guard: `write_file` / `edit_file` refuse the active config
  file, `AGENTS.md` / `SOUL.md` / `USER.md` under the data directory, soul and
  context directories, configured `soul_path`s and the path allowlist (#501).
- `write_memory` refreshes an existing structured memory row instead of
  appending a duplicate on every save (#505).
- Telegram replies forward the partially quoted text to the agent (#506).
- Dependency updates; Dependabot holds `@assistant-ui/react` below 0.15 and the
  Zed git crates until their dependents catch up.
- Security Audit: RUSTSEC-2026-0318/0319 ignored as unreachable until the
  matrix-sdk 0.19 upgrade (#510).

## Acceptance gates

- Every Rust and UI package reports `0.8.0`.
- Main CI and Extended CI succeed for the release commit.
- `microclaw-core`, `microclaw-engine`, and `microclaw-sdk` publish at `0.8.0`
  and pass the public API compatibility check.
- The `v0.8.0` workflow publishes verified binaries and multi-architecture
  containers, and the complete Release Assets workflow is green.
