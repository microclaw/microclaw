# MicroClaw v0.6.1 execution plan

Status: **Delivered**
Updated: **2026-09-04**

MicroClaw 0.6.1 is a release-quality patch. It preserves the 0.6 runtime and
SDK contract while making the complete Server, Work, SDK, container, and
documentation release path deterministic and repeatable.

## Acceptance gates

- Every Rust and UI package reports `0.6.1`.
- The complete local workspace test and Clippy gates pass.
- Web and documentation production builds pass without generated-doc drift.
- Release aggregation accepts every required Server, Work, and reliability
  artifact, rejects missing/unexpected files, and excludes Buildx internals.
- Main CI and Extended CI succeed for the release commit.
- `microclaw-core`, `microclaw-engine`, and `microclaw-sdk` publish at `0.6.1`
  and pass an immutable registry-consumer check.
- The `v0.6.1` workflow publishes verified binaries and multi-architecture
  containers, and the complete Release Assets workflow is green.
